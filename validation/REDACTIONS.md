# Redactions in the public repository

The public repository and release files were prepared from the development repository
on 25 November 2026. For privacy:

- The cluster job scripts `tools/athena_*.sh`, which several validation READMEs mention,
  are not included.
- User names, compute-grant names and home-directory paths in the validation records were
  replaced by the placeholders `<user>`, `<grant>`, `$HOME` and `~`.

Numerical results, test counts and images are unchanged. Commit identifiers and CI run
numbers quoted in these records refer to the development repository.
